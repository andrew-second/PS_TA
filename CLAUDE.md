# Candidate Tracker take-home

Graded take-home for Publicis Sapient. The brief is `Take-Home_FullStack_AI_Feature.pdf`, the plan is `docs/PLAN.md`, and choices are recorded in `docs/DECISIONS.md`.

## How to work here

- The author may have to change and explain this code in a live session, so explain each piece as it's built and prefer simple code over clever code.
- Work on one milestone at a time. Don't add tools or dependencies without agreeing them first.
- Never invent entries for `docs/AI_USAGE_LOG.md`. Point out possible entries; the author confirms them.
- Leave the personal content of `docs/LEARNING_LOG.md` to the author.
- Record significant choices and tradeoffs in `docs/DECISIONS.md`.
- Keep all LLM code in `server/src/summarizer/`, and treat resume text as untrusted data.
- Commit only when asked.

## Commands

- `npm install` installs everything.
- `npm run dev` starts the server on port 3001 and the client on port 5173.
